##Automotive Sensor Systems – Technical Investigation
Project Overview
This project was carried out as part of my academic coursework and focused on the investigation of automotive sensor systems and communication technologies.
As part of the project, I studied different types of PIR (Passive Infrared) sensors and investigated communication protocols and technologies relevant to embedded and automotive applications, including UART and Bluetooth communication.
The investigation involved understanding the operating principles, characteristics, advantages, limitations, and potential applications of different sensor and communication solutions. Based on this research and comparison, I evaluated their suitability for automotive applications.
The findings and technical analysis were then compiled into a technical report documenting the investigated sensor technologies, communication approaches, and their relevance to automotive systems.
Topics Investigated
Different types of PIR sensors
Automotive sensor systems
PIR sensor operating principles and characteristics
Sensor selection for automotive applications
UART communication
Bluetooth communication
Communication technologies for embedded systems
Comparison of different technical solutions
Suitability of sensors and communication technologies for automotive applications
Technical Report
The main outcome of this project is the technical report prepared after conducting the investigation and analysis of the different sensor systems and communication technologies.
The report was evaluated as part of my academic coursework and received a grade of 1.8 on the German grading scale.
